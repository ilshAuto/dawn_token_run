# DAWN Auto Script

## 功能特性 / Features
- ✨ 自动保活 / Auto Keep-alive
- 🔄 积分监控 / Points Monitoring
- 📊 社交绑定 / Social Binding
- 🔔 异常处理 / Error Handling

## 中文说明

### 项目说明
DAWN 自动化脚本，支持自动保活、积分监控、社交绑定等功能。

### 环境要求
- Python 3.9+

### 使用方法
1. 克隆仓库：
```bash
git clone https://github.com/ilshAuto/dawn_auto.git
```
或直接下载整个仓库ZIP文件

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 配置账户信息：
   在项目根目录创建 `dawn_files` 文件，按以下格式填写：
```
email----token----proxy
```
示例：
```
example@gmail.com----token----socks5://127.0.0.1:7890
```

4. 运行脚本
